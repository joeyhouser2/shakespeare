# Outside-evidence register

Newly reported or disputed evidence about de Vere, Shakespeare or Hand D, kept apart from the stylometric corpora.

- A row is a record of a **claim**, not an acceptance of it. `checked_how` says how far it was verified.
- Nothing here changes a pre-registered score, threshold or outcome.
- An item can join an analysis only if it supplies text meeting that analysis's pre-registered rules before its corpus is frozen.
- Use at triage (CLAUDE.md Phase 6): provenance, dating and competing explanations for a lead.

This list is not a systematic search. It holds what turned up on 2026-11-25.
